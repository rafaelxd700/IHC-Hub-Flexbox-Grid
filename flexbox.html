O que é Flexbox?

O Flexbox é um recurso do CSS utilizado para organizar e alinhar elementos dentro de um contêiner. Ele facilita a criação de layouts que se adaptam a diferentes tamanhos de tela.

Para utilizar o Flexbox, adicionamos display: flex; ao contêiner.

1. Direção dos elementos

A propriedade flex-direction define a direção dos elementos. Podemos utilizar row para organizar em linha ou column para organizar em coluna.

1
2
3
.container {
    display: flex;
    flex-direction: row;
}

2. Alinhamento e espaçamento

A propriedade justify-content distribui os elementos no eixo principal. Já align-items controla o alinhamento no eixo transversal.

1
2
3
.container {
    display: flex;
    justify-content: space-around;
    align-items: center;
}

3. Quebra de linha e espaçamento

Com flex-wrap: wrap;, os elementos podem passar para a linha seguinte quando não existe espaço suficiente. A propriedade gap define o espaço entre eles.

Caixa 1
Caixa 2
Caixa 3
Caixa 4
.container {
    display: flex;
    flex-wrap: wrap;
    gap: 15px;
}

4. Aplicações do Flexbox

O Flexbox pode ser utilizado em menus, barras de navegação, botões, cartões e outros componentes que precisam de alinhamento e distribuição de espaço.

Ele é indicado principalmente para layouts unidimensionais, organizados em uma linha ou coluna.
