O que é CSS Grid?

CSS Grid é uma ferramenta do CSS que permite organizar os elementos de uma página em linhas e colunas, facilitando a criação de layouts.

Principais propriedades

  • display: grid: ativa o CSS Grid.
  • grid-template-columns: define as colunas.
  • grid-template-rows: define as linhas.
  • gap: define o espaço entre os elementos.
